## New Features

- Add `SPELLBOOK.getSpellList(query)` to find a spell list page by UUID, name, or `{ identifier, type }`. Name and identifier lookups skip hidden and granted lists and prefer modified, custom, or merged copies.
- Add `SPELLBOOK.setSubclassSpellLists(actor, classIdentifier, uuids)` to set the subclass spell lists a class draws from on an actor.
- Spell lists of type other now appear in Class Rules and the Spell List Manager.

## Bug Fixes

- Changing a class's subclass spell lists now warns about and unprepares spells that leave the allowed lists, as class list changes already did.
- Updating class rules for a class with no saved rules now starts from the class defaults instead of writing a partial rule set.
