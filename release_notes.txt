## Bug Fixes

- A Spell Book opened before a class had a spell list now picks up a list assigned through the API without a reload.
- Loadout details now use a bullet separator instead of a stray glyph.
- Party Mode now shows a member's avatar for spells prepared or always available on the character sheet, not only spells prepared through the Spell Book.
- Range filters now compare spell ranges in the world's length units, so metric worlds filter feet and meters correctly.
- Selected spells in the current list now highlight their tick in selection mode.
- Spell books left behind by deleted actors now appear in the Spell List Manager as Player Spell Book custom lists that can be hidden.
- Spells with formula ranges, such as Spare the Dying, now show a resolved range in spell rows and range filters.
- Synergy Analysis now counts each unique and prepared spell once instead of once per copy.
- The Merged List Name field is now hidden when merging into an existing list, and the Create List dialog's Custom Identifier field is hidden unless Custom is picked.
- The Spell List Manager button now stays in the Compendium sidebar after it re-renders and appears in the popped-out directory.
- The Spell List Manager now labels custom, merged and modified list sources by kind instead of the pack name.
- The Spellcasting Gained chat notice is now spoken as the actor.
